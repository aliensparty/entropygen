# entropygen
small generator program of high entropy, easy to write passwords from simple english dictionary words
# usage
prereq: install lua ok :)
1. git clone https://github.com/aliensparty/entropygen
2. cd entropygen
3. lua main.lua
4. expected output: some passwords. for example, base-grand-match-doctor-doubt. a password who can have many characters but is easier to type than random letters and numbers.
