# entropygen
small generator program of high entropy, easy to write passwords from simple english dictionary words
# usage
prereq: install lua ok :)
1. cd into folder
2. lua main.lua
3. expected output: some passwords. for example, base-grand-match-doctor-doubt. a password who can have many characters but is easier to type than random letters and numbers.
